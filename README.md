# BJI Visual Stories

Projeto desenvolvido para a disciplina de **Projeto Integrador**, a partir de uma demanda real apresentada por **Lucas Benjamín Garcia Andrade**, responsável pela marca **BJI Visual Stories**.

A proposta consiste no desenvolvimento de um website institucional voltado à apresentação dos trabalhos fotográficos e audiovisuais do demandante, reunindo seus projetos, informações profissionais e formas de contato em uma única plataforma.

O desenvolvimento busca transformar as necessidades apresentadas pelo demandante em uma solução web visual, organizada e alinhada à sua identidade profissional.

---

## 1. Contexto do Projeto

O projeto foi desenvolvido a partir do contato com um demandante real durante a disciplina de **Projeto Integrador**.

O demandante, **Lucas Benjamín Garcia Andrade**, atua na área de fotografia e produção audiovisual por meio da marca **BJI Visual Stories**.

A partir da demanda apresentada, identificou-se a necessidade de desenvolver uma presença digital que permitisse apresentar seus trabalhos de maneira profissional, organizada e visualmente atrativa.

Com isso, foi proposta a criação de um website institucional que funcionasse como um portfólio digital, permitindo apresentar os trabalhos realizados, informações sobre o profissional e formas de contato.

O website foi desenvolvido inteiramente em **espanhol**, considerando o contexto do demandante e o público ao qual a marca se destina.

---

## 2. Objetivos

O desenvolvimento do projeto tem como principais objetivos:

* Desenvolver um website institucional para a BJI Visual Stories;
* Criar um portfólio digital para apresentação dos trabalhos realizados;
* Organizar os conteúdos de forma clara e visualmente atrativa;
* Valorizar as fotografias e produções audiovisuais do demandante;
* Apresentar informações sobre o profissional e seu trabalho;
* Facilitar o contato entre o demandante e possíveis clientes;
* Aplicar conceitos de UX/UI Design no planejamento da interface;
* Transformar as necessidades identificadas durante o projeto em uma interface funcional;
* Desenvolver uma solução baseada nos protótipos definidos durante o planejamento;
* Organizar o código e os recursos do projeto de forma estruturada.

## 6. Estrutura do Website

A estrutura definida para o website foi planejada para apresentar o trabalho da BJI Visual Stories de maneira objetiva e visual.

Entre as principais seções estão:

| Seção     | Descrição                                          |
| --------- | -------------------------------------------------- |
| Início    | Apresentação inicial e introdução ao trabalho      |
| Filmes    | Apresentação das produções audiovisuais            |
| Histórias | Apresentação dos trabalhos e histórias registradas |
| Sobre     | Informações sobre o profissional                   |
| Contato   | Canal para comunicação e novos projetos            |

A estrutura foi definida a partir do protótipo de alta fidelidade e das necessidades levantadas durante o desenvolvimento do projeto.
